# DSA learning track

Start with [Lesson 01: how work grows](lessons/01-complexity/README.md). Use the [Python warm-up](lessons/00-python/README.md) if its syntax is unfamiliar.

The [curriculum](../CURRICULUM.md) is the learning order: complexity → arrays/strings → hashing → array techniques → linked lists → stacks/queues → recursion/backtracking → sorting/searching → trees → heaps → graphs → greedy → DP → tries → advanced graphs → mixed interviews.

## How to use this folder

| Path | Purpose |
| --- | --- |
| [lessons/](lessons/) | Foundation lessons, exercises, and saved reasoning |
| [patterns/](patterns/) | Existing technique-specific material; folder numbers are resource IDs |
| [how-to-solve.md](how-to-solve.md) | Reasoning routine and later interview timing |
| [big-o-basics.md](big-o-basics.md) | Complexity refresher after Lesson 01 |
| [progress.md](progress.md) | Current module, attempts, gaps, and cold retries |
| [mock-interviews/](mock-interviews/) | Timed practice after the core checkpoint |

Pattern 01 is a developed lesson to use at D04. Patterns 02–15 are outlines, not full lessons or required unlocks. They will support the corresponding curriculum modules. Foundational lessons will introduce data structures before advanced techniques that depend on them.

New implementations use Python. Existing TypeScript examples are optional older material. Keep your drafts and reasoning as well as working code. Use [the attempt template](lessons/ATTEMPT_TEMPLATE.md) for new exercises; existing pattern `my-code/` folders still work for those exercises.

Bring an attempt back with “Review my reasoning” or “I'm stuck at this step.” We will address the first gap, then give you a chance to repair it before moving on.
