# DSA — Blind 75

This track uses a **learn → attempt → review** loop. A solution file is an answer key, not the first lesson.

## Your route through a pattern

1. Read the pattern primer and answer its MCQs.
2. Work through one **Learn together** anchor problem.
3. Attempt the next **Try yourself** problem without code or explanations.
4. Use hints only when you are genuinely stuck.
5. Compare your approach with the explanation and implement it in your strongest language first.
6. Reimplement or read the idiomatic Java, Python, and TypeScript versions.
7. Return after 1 day, 1 week, and 1 month without looking.

Begin at [Start here](00-start-here/roadmap.md). The full catalogue is in [Blind 75](02-blind-75/README.md).

## No-spoiler convention

Inside every problem directory, read files in numerical order. Do **not** open `03-explanation.md` or `solutions/` until you have made an honest attempt. The repository cannot technically hide a file from you, so its structure acts as the discipline.
