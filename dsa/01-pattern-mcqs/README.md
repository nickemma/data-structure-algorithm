# Pattern MCQs

Pattern questions train the crucial first step: deciding *what family of solution to try*. They are not trivia.

Each pattern folder will contain:

- a short recognition guide;
- scenario-based multiple-choice questions;
- an answer key that explains why tempting alternatives fail; and
- a short "say it aloud" interview drill.

Start with [Arrays & Hashing](arrays-and-hashing.md).
