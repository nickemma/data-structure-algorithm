# Pattern 11 — Binary Tree Traversal

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Four ways to visit every node — preorder, inorder, postorder, level-order — and knowing which one the question is secretly asking for.

## When to reach for it

From the article: "preorder: serialize or deserialize a tree", "inorder: retrieve elements in sorted order (BSTs)", "BFS: level by level scanning".
