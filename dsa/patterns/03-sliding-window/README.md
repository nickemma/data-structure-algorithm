# Pattern 03 — Sliding Window

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

One window over a linear structure that grows on the right and shrinks on the left, so every element is visited at most twice.

## When to reach for it

From the article: linear structures where you "must scan through a subarray or substring" and need the "shortest/longest/min/max".
