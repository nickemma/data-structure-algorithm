# Pattern 06 — Binary Search

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Halve the search space every step: O(log n) instead of O(n).

## When to reach for it

From the article: "input is sorted and you need to find a number" or "finding the position of insertion in a sorted list". Also any monotonic answer space ("smallest k such that...").
