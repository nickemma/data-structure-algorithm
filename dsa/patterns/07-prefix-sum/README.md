# Pattern 07 — Prefix Sum

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Precompute running totals once so any range sum becomes a single subtraction.

## When to reach for it

From the article: "cumulative sums are needed from index 0 to any element" or "querying subarray sums frequently across multiple ranges".
