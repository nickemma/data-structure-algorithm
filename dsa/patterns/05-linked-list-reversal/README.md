# Pattern 05 — In-Place Linked List Reversal

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Rewire `next` pointers as you walk, using three variables and no new nodes.

## When to reach for it

From the article: "reverse a linked list in 1 pass and O(1) space" or "reverse a specific portion of a linked list".
