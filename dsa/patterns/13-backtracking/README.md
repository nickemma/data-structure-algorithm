# Pattern 13 — Backtracking

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Build a candidate, recurse, then undo the last choice — brute force with a pruning rule.

## When to reach for it

From the article: "combinatorial problems (combinations, permutations, subsets)" or "constraint satisfaction (Sudoku, N-Queens)". Also: n is tiny (n <= 20).
