# Pattern 08 — Monotonic Stack

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

A stack kept sorted as you push, so each element finds its next greater/smaller neighbour in amortised O(1).

## When to reach for it

From the article: "find next greater or smaller element" or "find left/right boundary points in histograms or rectangles".
