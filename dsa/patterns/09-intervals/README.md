# Pattern 09 — Overlapping Intervals

**Status:** outline only. Follow [the curriculum](../../../CURRICULUM.md) for prerequisites and learning order.

## What it is (one line)

Sort by start, then sweep once and decide at each step whether the current interval extends or closes the previous one.

## When to reach for it

From the article: "merge or consolidate ranges", "schedule or find conflicts", or "find gaps or missing intervals".
