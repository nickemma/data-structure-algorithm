# DSA mock interviews

Every mock is a 45-minute simulation: clarify (5 min), discuss approach (8 min), code (20 min), test (7 min), and complexity/follow-ups (5 min).

| Mock | Focus | Problems |
| --- | --- | --- |
| 01 | Arrays & hashing | Two Sum, Product Except Self |
| 02 | Two pointers | Three Sum, Container With Most Water |
| 03 | Windows & stacks | Longest Substring, Valid Parentheses |
| 04 | Binary search & intervals | Rotated Search, Merge Intervals |
| 05 | Linked lists | Reverse List, Reorder List |
| 06 | Trees | Level Order, Validate BST |
| 07 | Graphs | Number of Islands, Course Schedule |
| 08 | Dynamic programming | House Robber, Coin Change |
| 09 | Tries & heaps | Implement Trie, Top K Frequent |
| 10 | Mixed final | Candidate-selected weak areas |

Start with [Mock 01](01-arrays-and-hashing.md) after completing Two Sum and Product of Array Except Self.
