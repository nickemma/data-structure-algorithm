# Mock — Two pointers

**Timebox:** 45 minutes  
**Candidate prompt:** Solve **Three Sum or Container With Most Water** from a blank editor.

## Run the interview

1. Spend five minutes clarifying input, output, assumptions, and examples.
2. Give a brute-force baseline and its complexity.
3. Choose the pattern, state the invariant, then code for 20 minutes.
4. Test a normal case, a boundary case, and a pattern-specific trap.
5. Close by stating time/space complexity and one follow-up trade-off.

## Self-review

Did you explain why every pointer move, stack pop, recursive call, or state transition preserves correctness? If not, revisit the corresponding pattern module before looking at a reference solution.
