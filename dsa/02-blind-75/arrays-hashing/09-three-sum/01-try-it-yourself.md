# Try it yourself — Three Sum

Spend 25 minutes before opening hints.

For `[-1, 0, 1, 2, -1, -4]`, return these unique triplets in any order:

```text
[-1, -1, 2]
[-1, 0, 1]
```

## Questions to answer before coding

- What does a three-loop brute-force solution need in order to avoid duplicate output?
- How does sorting change what you know about a pair sum that is too small or too large?
- Once you fix index `anchor`, what target should the remaining two values reach?
- Where must duplicate values be skipped?

Draw the pointers on the sorted version of the example.
