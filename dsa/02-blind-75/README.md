# Blind 75 catalogue

This is the canonical 75-problem track used by this repository. Each local module links to the original source and follows the candidate-first workflow; the complete guided reference implementations are added pattern by pattern.

**Roles:** Learn = guided anchor; Try = attempt before looking; Challenge = apply the pattern with more moving parts; Review = revisit under a timer.
