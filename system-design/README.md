# System Design

System design is structured trade-off analysis under uncertainty. You do not need a perfect architecture; you need to make reasonable assumptions, defend choices, and identify risks.

Start with [the roadmap](00-start-here/roadmap.md). Every lesson follows the same sequence:

1. What problem does this concept solve?
2. How does it work?
3. What does it cost?
4. When should you use or avoid it?
5. How would you explain it in an interview?

The curriculum is organised into [Foundations](01-foundations/README.md) and [Working at scale](02-working-at-scale/README.md), followed by realistic mock interviews.
