# DSA and system design, from the ground up

Build the ability to explain, implement, and adapt a solution to an unfamiliar problem.

**Primary language: Python 3.** Its compact syntax lets us focus on reasoning. We will learn the cost of its built-in operations as we use them. Go can be a later implementation exercise once a concept is comfortable.

## Start here

1. Read the [curriculum](CURRICULUM.md) for the learning order and checkpoints.
2. Open [Lesson 01: how work grows](dsa/lessons/01-complexity/README.md).
3. Answer its three questions in chat or in [your first attempt](dsa/lessons/01-complexity/attempt.md). Reason first; no implementation yet.
4. Bring your reasoning back for review. We will choose the next exercise from what your answer shows.

## How we learn

**Concept → intuition → implementation → worked example → exercises → interview problem → review.**

We study one small idea, trace it by hand, and implement it together. You then try a different problem. I review your reasoning and code, give one hint at a time when needed, and ask you to retry from a blank page. Early lessons are untimed; interview timing comes after you can explain why your approach works.

A passing submission is useful feedback. Readiness also requires a correctness explanation, accurate complexity, tests, and the ability to solve a changed problem without a template.
